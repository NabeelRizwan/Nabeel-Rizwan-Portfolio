# 🚀 Nabeel Rizwan Portfolio

Modern developer portfolio built using Next.js, React, TypeScript, and Tailwind CSS with smooth animations and responsive UI.

## ✨ Tech Stack

- Next.js
- React.js
- TypeScript
- Tailwind CSS
- Framer Motion
- Three.js

## 📌 Features

- Responsive Design
- Interactive UI
- Smooth Animations
- Project Showcase
- Modern Dark Theme

## 🚀 Run Locally

```bash
npm install
npm run dev
```bash

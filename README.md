# 🚀 Nabeel Rizwan Portfolio

🌐 **Live Demo:** [nabeel-rizwan-portfolio.vercel.app](https://nabeel-rizwan-portfolio.vercel.app/)

Modern developer portfolio built using Next.js, React, TypeScript, and Tailwind CSS with smooth animations and responsive UI.

## ✨ Tech Stack

- Next.js
- React.js
- TypeScript
- Tailwind CSS
- Framer Motion
- Three.js

## 📌 Features

- Responsive Design
- Interactive UI
- Smooth Animations
- Project Showcase
- Modern Dark Theme

## 🚀 Run Locally

```bash
npm install
npm run dev
```

For the local cinematic intro preview, replay controls, tuning settings, and verification notes, see [INTRO-REVIEW.md](INTRO-REVIEW.md).
